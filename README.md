# AlgoStreak Club

Daily algorithm challenge for a small group of friends. One shared problem per day (UTC), solved locally and submitted as a Pull Request into `solutions/<github-username>/`. A green check plus merge before the end of the challenge's UTC date counts towards your streak.

Status: MVP 0, in setup. See [docs/specs/mvp-0-club-repo.md](docs/specs/mvp-0-club-repo.md).
